\begin{abstract}
Person re-identification ranks gallery photographs so that other views of the person in a query crop come first.
This paper asks how much of that ranking survives when half of the patch tokens are removed from a frozen vision transformer.
The encoder is the published CLIP-ReID ViT-B/16 checkpoint trained on Market-1501.
It is not retrained.
On the standard single-query test the full token sequence scores 89.41\% mAP and 94.98\% Rank-1, against the published 89.6\% and 95.5\%.
Each $256 \times 128$ crop enters the network as 128 patch tokens plus one class token.
After layer 6, the class token keeps the 64 patches it attends to most, and layers 7--12 run on 65 tokens instead of 129.
On the same 3{,}368 queries the pruned encoder scores 74.86\% mAP and 88.93\% Rank-1.
k-reciprocal re-ranking on the pruned features recovers the score to 88.40\% mAP, which is still below the unpruned list.
The class token is never dropped.
On an illustrated query the surviving patches cover the person and the discarded patches are mostly background.
The result is the measured cost of that cut, not a claim that pruning improves re-identification.
\end{abstract}

\section{Introduction}
A re-identification system receives one cropped person and a gallery collected by other cameras.
Its output is an ordering, not an identity in a closed set.
Market-1501 made this protocol standard: 751 people for training, 750 disjoint people for testing, and a fixed rule for which gallery hits count \cite{zheng2015market}.
CLIP-ReID later showed that a CLIP image encoder, adapted without requiring a text label at inference, is a strong ranker on that benchmark \cite{li2023clipreid,radford2021clip}.

The encoder is a vision transformer \cite{dosovitskiy2021vit}.
A $256 \times 128$ crop is divided into 128 patches.
Those patches, together with one class token, pass through all 12 layers, but the vector used for search is built only from the class token.
The patch tokens are therefore computed in full and then discarded, except for the information they have already written into the class token through attention.
Token pruning asks whether the later layers need every patch \cite{liang2022evit}.

This paper makes one controlled cut inside a checkpoint that was not trained to be pruned.
After layer 6, only the patches most attended by the class token continue.
The same Market-1501 test is then repeated.
The question is not whether a shorter sequence can beat the published model.
The question is how person ranking changes when half of the patches are removed and nothing else is retrained.

\section{Related work}
Market-1501 collects six cameras in an outdoor campus scene and evaluates single-query search after removing junk detections and same-camera matches of the query identity \cite{zheng2015market}.
The numbers below use that protocol and do not add the optional 500{,}000 distractors.

CLIP-ReID starts from CLIP's image tower and learns re-identification prompts and an image encoder on the training split \cite{li2023clipreid}.
The published ViT result without side-information embeddings and without online instance matching is 89.6\% mAP and 95.5\% Rank-1.
This project loads that released ViT-B/16 checkpoint and does not repeat its training.
Camera side-information embeddings are off, matching the published row used for comparison.

A vision transformer mixes a class token with a grid of patch tokens \cite{dosovitskiy2021vit}.
EViT showed that the class token's attention is a usable score for discarding patches, and that the later blocks can run on the reduced sequence \cite{liang2022evit}.
That work trains and evaluates the idea on image classification.
The experiment here copies the selection rule, applies it once at inference, and measures person re-identification instead of classification accuracy.
No pruning weights are learned.

k-reciprocal re-ranking is a feature-space method from 2017 \cite{zhong2017kreciprocal}.
It is reported on both the full and the pruned features, with the original neighborhood sizes $k_1{=}20$, $k_2{=}6$, and mixture weight $0.3$.
The CLIP-ReID code uses a larger neighborhood; that variant is not substituted.
k-reciprocal does not see the image tokens.
It tests whether a standard reranker can repair a list that was built from a shorter token sequence.

\section{Method}
\subsection{Unpruned ranking}
Each crop is resized to $256 \times 128$ and encoded by the CLIP-ReID ViT-B/16, with patch size 16, stride 16, and camera side-information embeddings switched off.
The patch grid is $16 \times 8$, so the sequence length is $128 + 1 = 129$.
The search vector is the concatenation of the batch-normalized class token and the batch-normalized projection of that token, an $\ell_2$-normalized vector of 1{,}280 dimensions.
For a query vector $q$ and a gallery vector $g$, the score is the cosine
\begin{equation}
v = q^{\top} g.
\end{equation}
Gallery entries whose filename marks them as junk are removed before ranking.
A gallery photograph of the same person taken by the same camera as the query is ignored when mAP and Rank-$k$ are computed.

\subsection{Where the tokens are cut}
The first six transformer layers run on all 129 tokens.
At layer 6 the attention weights are averaged over the 12 heads.
The score of a patch is the attention from the class token to that patch.
The 64 highest-scoring patches are kept and written back in their original left-to-right, top-to-bottom order.
The class token is always kept, so layers 7--12 receive 65 tokens.
Position vectors are not recomputed: each surviving token already carries the position that was added before layer 1.
The search vector is read from the class token in the usual way.
When the keep ratio is 1, the original 12-layer path is used unchanged, so the baseline is the unpruned checkpoint.

The cut is deliberately simple.
There is one pruning layer and one keep ratio.
The checkpoint is frozen.
A learned pruner, a second pruning stage, or a search over layers would be a different experiment, and those settings are not reported here.

Keeping half of the patches costs 14.55 points of mAP and 6.05 points of Rank-1.
Rank-10 falls only from 98.99 to 97.57.
The first true match is often still near the front, while the order of the rest of the true matches is worse, which is why mAP moves more than Rank-1.
k-reciprocal recovers 13.54 points of the pruned mAP, from 74.86 to 88.40, and still finishes 1.01 points below the unpruned encoder and 6.08 points below k-reciprocal on the full tokens.
A separate raw top-five check, computed before same-person same-camera removal, finds a true cross-camera match in that prefix for 90.88\% of queries, down from 93.76\%.
That figure is not CMC Rank-5, which is 95.84 after the protocol filter.
The share of all true gallery matches that sit in those five raw positions falls from 16.88\% to 15.90\%.
Pruning therefore does not only reshuffle a short list.
It changes the features of every query and every gallery image before any list is built.

On this query against five gallery crops, the different identity stayed last with and without pruning, while two photographs of the same person exchanged second and third place.

\section{Discussion}
The experiment has one intervention and a matched pair of evaluations.
The person, the cameras, the checkpoint, and the metric stay fixed.
Only the token sequence changes.
That is what makes the 14.55-point mAP gap interpretable: it is the cost of discarding the 64 patches the class token attended to least, inside a model that still expected to see them.

Two observations keep the result from being only a lower number.
First, Rank-10 stays high, so identity evidence is concentrated in the patches the class token already prefers.
The figure agrees with that reading on one image: the kept blocks lie on the body.
Second, k-reciprocal can repair a large part of the damage without looking at tokens at all.
The pruned vectors are weaker, and they are not unstructured.
Neighbor relations among them still carry identity.

The limits are equally specific.
The keep ratio is one half, and the cut is only after layer 6.
A later layer would discard less computation and might discard less accuracy.
An earlier layer would do the opposite.
This paper does not report that sweep, so it does not claim that layer 6 or 64 patches is the best operating point.
The checkpoint was not fine-tuned after the rule was inserted.
A model trained with the same drop could close some of the gap, and that comparison is not available here.
Finally, the selection rule is the class-attention rule from image classification \cite{liang2022evit}.
The contribution is the measurement of that rule on person re-identification, under a frozen CLIP-ReID checkpoint and the official Market-1501 protocol.

\section{Conclusion}
A frozen CLIP-ReID checkpoint reproduces the published Market-1501 operating point at 89.41\% mAP and 94.98\% Rank-1.
Inside that transformer, the class token selects 64 of 128 patches after layer 6, and the remaining layers rank people from 65 tokens instead of 129.
On all 3{,}368 queries the pruned ranking scores 74.86\% mAP and 88.93\% Rank-1.
k-reciprocal raises the pruned result to 88.40\% mAP and does not recover the unpruned list.
Half of the patches can be removed without losing the person in the token map, and the ranking pays 14.55 points of mAP for that removal.
